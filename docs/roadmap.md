## Фаза 1 — Первый проект ⏳
Выбираем один из треков:
1. **Сайт** — лендинг/портфолио/продукт → деплой на Pages
2. **Игра** — веб-игра (TS) или прототип в UE5
3. **Агент** — автоматизация (бот, парсер, пайплайн)
4. **Видео** — продуктовый ролик в Raylight для одного из существующих проектов

## Фаза 2 — Конвейер запуска
Шаблон нового проекта: `репо → спека → дизайн → код → тесты → деплой → ролик`.
Цель: новая идея становится живым продуктом за один присест.

## Фаза 3 — Витрина
Страница-портфолио со всем, что построено на этом хабе + трейлеры из Raylight.
